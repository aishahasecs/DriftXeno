# DriftXeno

DriftXeno utilizes intelligent edge computing to enable real-time, adaptive auto-scaling for high-performance streaming-analytics engine.

DriftXeno is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/DriftXeno.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DriftXeno, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
